The user has a high, specific design bar and reacts strongly against **"AI-like" UI**: uniform card grids, every section as eyebrow→title→subtitle→grid, a sea of equal rounded cards with soft shadows, pill chips everywhere, safe symmetric layouts. A first pass that was "competent/clean" was rejected as "mid."

What landed: **distinctive, crafted, editorial** design with real structural variety — a layout chosen per content type, asymmetry, strong typographic hierarchy, hairline rules + whitespace over boxes/shadows, a committed point of view. For the emoji-meanings homepage this became **"The Field Guide"** (a typeset reference-book aesthetic). See [[tailwind-v4-color-token-override]].

**How to apply:** For any UI work here, don't default to card-grid templates. Propose a real, opinionated design direction (use the ui-ux-pro-max skill), avoid generic-AI tells, and lock the *art direction* with the user before building broadly — they'd rather choose a strong direction than receive a safe one. Keep given content verbatim unless asked.
